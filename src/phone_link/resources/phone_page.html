Lexus Head Unit: phone position

Not sharing
Keep this page open while driving; Safari stops sharing when it is in the background or the phone locks.

First time only: install the head unit's certificate, then in Settings, General, About, Certificate Trust Settings, turn on full trust for "Lexus Head Unit local CA". Allow location for Safari websites when asked.

The position goes only to the head unit on this hotspot. It is shown on the map and never written to a file.
